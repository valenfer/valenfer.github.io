# Interactive Quadcopter Anatomy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish a standalone Anatomy interactive quadcopter model at `recreaciones/dron/` in `valenfer/valenfer.github.io`.

**Architecture:** Use the Anatomy framework-free SVG/HTML kit. Keep a pure flight model for RPM, thrust, attitude and power, render the quadcopter as a dense isometric instrument, and drive controls/readouts from the same state. Publish as relative-path static files inside the existing GitHub Pages repository.

**Tech Stack:** Node.js built-in ESM, Anatomy `iso-kit.mjs`, standalone HTML/SVG, vanilla JavaScript, GitHub Pages.

**Spec:** In-chat approved design for the interactive quadcopter Anatomy figure.

## Global Constraints

- Do not modify the installed Anatomy skill directory.
- The final page must work from `recreaciones/dron/index.html` with relative assets only.
- RPM changes must visibly rotate propellers and update thrust, tilt and consumption.
- Include dark and light themes where supported by the Anatomy page builder.
- Verify build, browser rendering, responsive layout and GitHub Pages source/public output before claiming completion.
