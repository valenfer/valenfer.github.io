# RadarIA

Archivo público en GitHub Pages para los informes diarios de Radar IA.

URL prevista: https://valenfer.github.io/radaria/

El cron diario debe:
1. investigar novedades de IA;
2. enviar el correo HTML a `valenfer71@gmail.com`;
3. guardar una copia HTML en `radaria/informes/YYYY-MM-DD.html`;
4. actualizar `radaria/reports.js`;
5. hacer commit y push a `valenfer/valenfer.github.io`.
