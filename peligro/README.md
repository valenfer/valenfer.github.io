# Peligro Legal

Web estática experimental con ocho laboratorios educativos sobre ideas "peligrosas pero legales": privacidad, propaganda, IA, crisis y pensamiento crítico.

## Tecnología utilizada

- HTML5 semántico.
- CSS3 moderno: variables, responsive design, grid, sticky tabs, estados accesibles.
- JavaScript vanilla: sin frameworks, sin servidor y sin dependencias externas.
- GitHub Pages como alojamiento público bajo `https://valenfer.github.io/peligro/`.

## Cómo usarla

1. Abre `index.html` en local o visita la URL pública.
2. Usa las pestañas para cambiar de laboratorio.
3. Prueba las herramientas interactivas:
   - medidor de huella digital,
   - analizador de sesgo,
   - generador de debate histórico,
   - simulador de crisis,
   - detector de phishing ético,
   - reescritor de noticias sesgadas,
   - mapa ficticio de vigilancia,
   - escape room sobre IA.

## Aviso ético

Todo el contenido está diseñado para aprendizaje, simulación y pensamiento crítico. No incluye recolección de datos reales, ataques, campañas ni acciones contra terceros.
