El lado cliente

El cliente es lo que ocurre en el navegador: interfaz, eventos, validación inmediata, llamadas a APIs, estados visuales y rendimiento percibido.

DOM

Selecciona elementos, modifica contenido y crea interfaces dinámicas sin perder estructura semántica.

Eventos

Click, submit, input, teclado y puntero: la interfaz responde a intención humana, no a magia negra.

Fetch y APIs

Consume datos externos, muestra estados de carga, maneja errores y valida lo recibido.

Formularios

Campos claros, validación amable, mensajes útiles, accesibilidad y prevención de envíos basura.

Estado local

LocalStorage, sessionStorage y memoria para pequeñas preferencias o prototipos.

Frameworks

React, Vue, Angular o Svelte ayudan cuando la UI crece, pero primero conviene dominar JavaScript base.

Buenas prácticas rápidas
  • Carga solo lo necesario.
  • Evita bloquear la interfaz.
  • No confíes en validaciones solo del cliente.
  • Comprueba móvil y teclado antes de publicar.
