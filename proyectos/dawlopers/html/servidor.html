backend / datos / seguridad

El lado servidor

El servidor es donde vive la lógica crítica: valida datos, guarda información, aplica permisos, habla con bases de datos y responde al cliente con orden.

HTTP y rutas

GET, POST, PUT/PATCH y DELETE organizan la conversación entre navegador y servidor.

APIs REST

Endpoints claros, respuestas JSON, códigos de estado correctos y documentación mínima.

Bases de datos

Modela entidades, relaciones, consultas, índices y migraciones. Sin datos fiables no hay app seria.

Autenticación

Sesiones, tokens, roles y protección de rutas. Lo privado no se protege con “ya se verá”.

Seguridad básica

Validación en servidor, variables de entorno, CORS, límites de petición y cuidado con archivos subidos.

Despliegue

Logs, variables, entornos, backups y monitorización. Publicar no es rezar a San Deploy.

Tecnologías habituales

Node.js con Express o Fastify, PHP con Laravel, Python con Django/FastAPI, Java con Spring y bases de datos como PostgreSQL, MySQL, SQLite o MongoDB.
