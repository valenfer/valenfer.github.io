Acerca de DAWLOPERS

Esta web fue creada para las tareas prácticas de la asignatura de Horas de Libre Configuración del grado de Desarrollo de Aplicaciones Web del curso 2023/2024 por Valentín Fernández Guijarro.

La versión actual funciona como laboratorio de recursos: una base para consultar conceptos, herramientas y rutas de aprendizaje mientras se construyen proyectos web reales.
